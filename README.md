# Starpedia 3D: Stars of the Universe

**Starpedia 3D** is an interactive 3D astrophysics catalog and cosmic scale explorer built with React, Three.js, and GenAI. Taking universe scale comparisons into an immersive 3D space, users can journey from dense neutron stars to colossal red hypergiants.

🌐 **Live Demo:** <https://starpedia3d.vercel.app/>
🔗 

**Repository:** <https://github.com/thisisbarbelixir123/All-about-stars>

## ✨ Features

* **Interactive 3D Environments:** Explore stars in 3D space using Three.js and React Three Fiber.

* **Cosmic Scale Comparisons:** Visually compare the sizes of different celestial bodies, from Earth-sized white dwarfs to massive supergiants.

* **AI-Powered Astrophysics:** Integrated with Google's GenAI SDK to generate dynamic, real-time facts and insights about specific stars and astronomical phenomena.

* **Modern UI:** Built with Tailwind CSS for a sleek, responsive, and space-themed user interface.

## 🛠️ Tech Stack

### Frontend

* **React.js** - UI framework

* **Three.js & @react-three/fiber** - 3D rendering and canvas management

* **Tailwind CSS** - Styling and responsive design

* **Vite** - Build tool and development server

### Backend & AI

* **Node.js & Express.js** - API server for handling requests

* **Google GenAI SDK** - AI integration for generating cosmic insights

## 🚀 Getting Started

Follow these instructions to set up the project locally.

### Prerequisites

* [Node.js](https://nodejs.org/) (v18 or higher recommended)

* npm or yarn

### Installation

1. **Clone the repository:**

   ```
   git clone https://github.com/thisisbarbelixir123/All-about-stars.git
   cd All-about-stars
   
   ```

2. **Install dependencies:**
   *(Assuming a standard full-stack setup, you may need to install dependencies in both frontend and backend directories)*

   ```
   npm install
   
   ```

3. **Set up Environment Variables:**
   Create a `.env` file in the root of your backend or project directory and add your Google Gemini API key:

   ```
   GEMINI_API_KEY=your_google_genai_api_key_here
   PORT=5000
   
   ```

4. **Run the application:**
   Start the Vite development server and the Express backend:

   ```
   npm run dev
   
   ```
